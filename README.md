# RimWorld Lilly Pack (Test)

This repository is a test-only RimWorld mod container.

Standalone mods that have been split into their own repositories are maintained there and must not be duplicated in this test pack. The former Cheat Genes Defs and gene textures now live in [Cheat Genes By Lilly](https://github.com/RimWorldLilly/Cheat-Genes-By-Lilly).

The test pack currently contains no gameplay Defs or textures. Use it only for validating mod packaging and future integration experiments.

- Package ID: `Lilly.RimWorldLillyPack`
- Supported RimWorld version: 1.7
